# 品牌展示与动态作品墙

用于品牌表达、设计团队、作品集、发布和展览页。工具、资料库和技术讲解页不要仅因参考了展示站就套超大 Hero。

## 一个主张，而不是一排卖点

首屏只表达一个与品牌密切相关的判断。让标题本身成为视觉主角，正文保持短而具体；不要在同一屏同时放口号、三组指标、功能卡片和多个 CTA。

大标题需要实际排版，而不是把默认字号放大：

- 根据容器宽度、词长和语言设置尺度与换行，桌面可以接近版面边缘，手机必须自然重排。
- 使用 `clamp()` 时仍检查最窄视口、200% 缩放和长翻译，不以固定换行掩盖溢出。
- 英文展示字体常见的紧字距不能直接套给中文；中文优先检查字面密度、行距和标点。
- 大标题与较小正文形成尺度对比，但正文、导航和媒体标签仍要清晰可读。
- 不靠给单个词加斜体或渐变制造“设计感”；整个标题的构图才是重点。

## 留白承担节奏

展示页可以用大面积留白把品牌主张与作品分开，但留白必须有边界：下一段内容应在继续滚动后准时出现，不制造“页面没加载完”的空白。手机减少无意义垂直距离，不让用户为每个装饰屏反复滑动。

## 作品墙展示真实证据

- 使用真实产品界面、过程稿、访谈、活动或明确标注的示例；不用生成图冒充项目成果。
- 让媒体比例和内容差异形成节奏，同时保持共同的对齐线；不要给所有素材再套相同卡片。
- 每个作品有可访问名称和明确入口。点击后应能看到项目背景、角色或实现细节，而不是只放大视频。
- 视频海报本身也应构成完整画面；加载失败时保留海报与作品入口。
- 只有媒体确实是重点时才使用多视频作品墙；技术讲解页优先一个可控制的机制演示。

## 动效与媒体预算

自动播放仅用于静音、装饰或预览媒体，并提供暂停；离开视口时暂停，非首屏媒体延迟加载。设置海报、宽高和 `playsinline`，避免布局偏移与手机意外全屏。

滚动叙事必须对应内容变化，例如从问题到作品、从草图到成品。不要为“高级”把每次滚动都变成遮罩、视差和缩放。减少动态效果时展示静态海报和完整阅读顺序。

交付前检查首屏和慢网：没有黑帧、空白媒体、同时下载整页视频或滚动阻塞。不能验证视频手感时明确标为未验证，不用截图宣称动效通过。

## 减法检查

遮住大标题后，作品本身是否仍有辨识度？遮住作品后，品牌主张是否仍成立？两者都依赖对方但都能独立表达，才值得保留。若删掉视频墙只剩空泛口号，应补真实内容而不是再加特效。
