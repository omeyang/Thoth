# 交互与无障碍

## 交互决策

每次加动效前依次判断：

1. 用户多久看到一次？高频操作应即时或极短反馈。
2. 动效表达空间关系、状态变化、因果还是操作反馈？答不出就不动。
3. 用户能否在中途反向操作？能则用可中断过渡，不让动画锁死输入。
4. 减少动态效果后，信息是否仍完整？

普通控件反馈从 100–160 ms 开始，菜单/提示从 125–200 ms 开始，抽屉和对话框可按距离适当延长。进入偏 ease-out，退出通常更快。不要对所有属性使用过渡。

## 必备状态

- 按钮/链接：默认、hover（适用设备）、active、focus-visible、disabled、busy。
- 输入：有意义的标签、正确类型、提示、校验错误、修复方法；不阻止粘贴。
- 异步：保留操作上下文，结果用可感知反馈表达；失败后能重试。
- 集合：加载、空、部分失败、长内容、大量内容；不只设计理想数据。
- 弹层：焦点进入、Tab 不逃逸、Escape 关闭、焦点返回触发者；背景不可误操作。

## 语义与键盘

- 动作用 `button`，导航用 `a`；不要用带 click 的 `div` 模拟。
- 图标按钮有 `aria-label`；装饰图标对辅助技术隐藏。
- 图片有符合用途的 `alt`，纯装饰图使用空 `alt`。
- 标题层级连续，页面有主区域；长页提供跳至主要内容链接。
- 焦点样式清晰，不移除 outline 而不给替代；sticky 区域不能遮住焦点。
- 异步状态在合适位置使用 `aria-live`，避免重复播报整页。

## 触控与响应式

触控目标要足够大且彼此有间距；hover 不是唯一入口。拖拽、滑动和路径手势提供点击与键盘替代。手机输入字号避免触发意外缩放，固定区域考虑 `env(safe-area-inset-*)`。

测试 200% 缩放、长翻译、长用户名、空列表和极短内容。不要禁用页面缩放，不要用隐藏横向溢出来掩盖布局问题。

## 动效与性能

优先 transform/opacity；动画循环提供暂停，并在 `prefers-reduced-motion: reduce` 下停止非必要运动。减少动态效果不等于删除所有反馈，可保留即时状态和轻微透明度变化。

自动播放预览视频应静音、内联播放、带静态海报，并在离开视口时暂停；加载失败后仍可打开作品。减少动态效果时使用静态海报，不自动切换画面。

避免在主线程每帧读写布局。首屏媒体有尺寸，非首屏图片与视频延迟加载；不为了一个小效果引入大型动画或 3D 依赖，也不在未节流的作品墙中同时下载全部视频。
