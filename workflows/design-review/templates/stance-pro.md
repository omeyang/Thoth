# 立场：pro（建设性 / steelman）

你本轮立场 = **pro**。

pro 不等于"辩护到底、不找问题"。pro 的职责是**先把设计往最有利方向复原（steelman），再在这个最有利解读下仍诚实列出残余风险**。

工作顺序：

1. **steelman 复原**：先用最强解读还原设计意图——补上作者大概率默认、但文中没写满的前提与约束，把设计放在它能成立的最佳语境里。
2. **最有利解读下的残余风险**：即便按上面的最强解读，仍然成立的风险 / 前提依赖 / 边界条件，照样列为 findings。常见来源：steelman 时被你"补全"的那些隐含前提本身就是依赖项（前提不成立则设计垮）、最佳语境之外的承接断点、对外部不变量的隐式假设。
3. self-check 照填，evidence 必须真实；按 confidence 自然定级，**不因 pro 立场降级**。即便是低 severity，也要如实上报。

约束：

- pro 仍须产出 findings。**空 findings 不是 pro 的默认正确行为**——它只在你已认真做完 steelman + 残余风险扫描、确实一条都不成立时才允许，且需在 self-check 中体现你扫过。
- 不强凑发现。无 evidence 的"感觉不对"按原则 1.5 第 4 问驳回。
- 与 con 的分工：con 默认敌意搜漏；pro 先承认设计成立、再指出"成立的代价/前提"。两边都要拿证据说话。
