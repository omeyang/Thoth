# 技能包目录

技能包总数：3（与当前技能目录保持一致）

安装后按客户端支持的方式显式调用，或让 Agent 根据 description 自动选择。

| 技能包 | 描述 |
|---|---|
| [`explain-business-visually`](explain-business-visually/SKILL.md) | 把已有业务材料和技术问题讲得清楚、具体、可复述，覆盖费曼、表达结构、主谓宾、贴切示例、场景边界、动画和 teach-back。 |
| [`ui-craft`](ui-craft/SKILL.md) | 设计、实现、重塑和评审有辨识度且易用的 UI/UX，覆盖中文排版、视觉层级、响应式、交互、动效和真实浏览器验收。 |
| [`verify-business-reality`](verify-business-reality/SKILL.md) | 对业务分析、代码改动、故障复盘和方案决策执行求实、求是、防幻觉、正证反证和影响链核查。 |
