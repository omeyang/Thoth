# Thoth 决策记录

## 2026-11-20：按理解与决策目标全面重写

**状态：已实施。**

### 决策

Thoth 从综合插件仓库改为只维护业务图解与 UI 工艺两个技能。删除其余技能、代理、Hook、MCP、模板、工作流和宿主插件清单，避免旧入口继续描述已不存在的仓库。

业务图解采用三层模型（事实、理解、行动）和四步流程。费曼稿、证据台账与 teach-back 必选，其余机制按读者卡点选择。`content.json` 只强制六个核心字段，静态页面不再需要动画或播放器。

### 理由

旧仓库和旧技能主要优化结构完整度，不能证明陌生读者真正理解。保留无关能力会分散维护与验收，也会让文档继续诱导旧使用方式。

### 后果

- 旧插件安装方式和 `/thoth:<skill>` 调用不再由当前仓库提供。
- 旧能力仍可从 Git 历史恢复，但不属于当前支持范围。
- 共享 HTML 卫生检查只有一份实现；独立安装包在构建时注入该依赖。
- 自动检查、浏览器验收和独立盲测必须分别报告，不能相互冒充。
